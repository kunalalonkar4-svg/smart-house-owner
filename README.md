# Smart House Owner

Ghar banwane walon ke liye **free** app (Hinglish + हिंदी). Engineer roz nahi aa sakta, aap roz check kar sakte ho.

**App kholo:** https://kunalalonkar4-svg.github.io/smart-house-owner/

## Features
- 10 stages ki checklist (Sahi / Galat), videos aur thekedar se poochne wale sawal
- Photo se Problem Check: photo + chhote sawal → problem, severity, wajah, repair, videos
- Follow-up photo se tulna (problem badhi ya nahi), bolkar jawab, thekedar / engineer ko WhatsApp
- Red flags, engineer se video call / site visit
- Material calculator (concrete, eent, plaster, sariya), material quality guide
- Kharch tracker (bill photo ke saath), thekedar payment milestones
- Photo diary (date, location), roz ka kaam, reminders (curing, shuttering, cube test)
- Aam galtiyan library, House health card (PDF)
- Phone me install, offline chalta hai, data sirf phone me (backup / restore)
